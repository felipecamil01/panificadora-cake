# Panificadora Cake

Site estático em HTML, CSS e JavaScript. Não exige npm, instalação ou compilação.
Localização: Três Lagoas, Foz do Iguaçu, PR.

## Abrir no computador
Abra index.html em um navegador moderno com JavaScript habilitado. As fontes do Google precisam de internet. O botão de copiar pode exigir HTTPS; há uma alternativa de cópia manual.

## Colocar no GitHub
1. Extraia este ZIP.
2. Crie um repositório no seu GitHub.
3. No repositório, escolha Add file > Upload files (ou uploading an existing file em um repositório vazio).
4. Envie os arquivos extraídos, mantendo index.html na raiz.
5. Confirme com Commit changes.
Enviar ao GitHub salva o código. Publicar um endereço de site é uma etapa separada.

## Arquivos
- index.html: estrutura, textos e formulários.
- style.css: identidade visual, preto e dourado, e layout responsivo.
- app.js: busca, categorias, detalhes de produtos e pedido.
- menu-data.js: dados do cardápio carregados pelo site (CAKE_MENU).
- menu.json: cópia dos mesmos dados em JSON; mantenha sincronizada ao editar menu-data.js.
- Arquivos JPG e favicon.svg: imagens e ícone.
- ASSETS.md: procedência das imagens.
- MENU-SOURCES.md: referências e contexto da seleção do cardápio.

## Funcionamento atual
São 32 salgados e 31 bebidas de exemplo, além de bolos e buffet. Não são estoque ou preços confirmados da Cake. Os pedidos ficam na memória da página e são perdidos ao recarregar. O cliente copia a solicitação e a envia pelo Instagram. Não há pagamento online, banco de dados, envio automático ou painel administrativo.

## Imagens
As fotografias são ilustrativas. Consulte ASSETS.md para créditos e situação das licenças; algumas imagens de terceiros não têm licença de reutilização confirmada. Para uso comercial, substitua essas imagens por fotos próprias ou devidamente licenciadas.
